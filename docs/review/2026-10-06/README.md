## 1. После отчёта аудита

**Telegram-текст:** `platforms.telegram.content` в JSON. Он содержит рабочий вопрос и мягкое приглашение к 15-минутному обсуждению обезличенного последнего аудита.

**Отдельный мини-опрос Telegram:** «Где чаще прерывается путь после отчёта внутреннего аудита?» Варианты: назначение ответственного / контроль срока / доказательство выполнения / проверка результативности / другое. Указывать один выбор; ответы не считать репрезентативными для рынка. Публиковать опрос только вместе с согласованным материалом, отдельным действием владельца.

**Бриф визуала:** отчёт → решение → ответственный → срок → проверка, один главный образ в фирменной синей палитре. PNG подготовлен генератором изображения как концептуальная иллюстрация без текста и без интерфейса продукта. Заголовок оставить в подписи; основатель может решить, нужен ли он на карточке.

## 2. Первое сообщение о событии

**Telegram-текст:** `platforms.telegram.content` в JSON. Он предлагает назвать первый барьер и добровольно обсудить или попробовать учебный сценарий без данных пациентов.

**Отдельный мини-опрос Telegram:** «Что первым мешает сотруднику сообщить о нежелательном событии?» Варианты: нет времени / сложно заполнить / опасение последствий / неясно, что будет дальше / другое. Один выбор. Желательно отдельно спросить сотрудников, поскольку аудитория канала может состоять преимущественно из специалистов по качеству.

**Бриф визуала:** короткий путь от наблюдения к ответу команды, светлая схема в палитре AUQNI. PNG подготовлен генератором изображения как концептуальная иллюстрация без текста, пациентов и интерфейса продукта. Схема не утверждает, что весь маршрут автоматизирован.

## Перед решением о публикации

Проверить формулировки и визуалы, фактический путь личного контакта, доступность опроса и актуальные границы продукта. Для опроса и контактов действуют приватные исследовательские записи; в публичных комментариях не собирать данные пациентов или названия организаций. Вопросы к автору и эксперту в JSON касаются версий для сайта и не означают, что Telegram уже согласован.

Офлайн-проверка выполняется штатным `telegram_publish.py --dry-run --content-json … --image …`. `--publish` не использовать до отдельного решения владельца.
