# Visual Guide AUQNI Content v1

## Назначение и референсы

Визуальный язык публикаций AUQNI: QualityTech, SaaS, управление качеством, данные, система и непрерывные улучшения. Один визуал передаёт **одну главную мысль**. Обычно Telegram-карточка содержит один короткий заголовок (3–7 слов), один главный образ или систему и оригинальный бренд-ассет, если для фона есть пригодный вариант. Абзацы поста и второй лозунг на изображение не переносить.

Локальная референсная база: [`visual-references/brand`](../visual-references/brand/), [`visual-references/moodboard`](../visual-references/moodboard/) и [`visual-references/pinterest`](../visual-references/pinterest/). Moodboard показывает четыре направления, а не точность логотипа или интерфейса. Pinterest и moodboard служат только ориентирами по композиции, глубине, пространству, карточкам, сетям, digital/SaaS-характеру, градиентам и сочетанию светлого с тёмным. Не копировать чужие логотипы, тексты и конкретные макеты или композиции. Изображения с шестигранниками не превращать в химические молекулы.

## Палитра и режимы

| Цвет | HEX |
| --- | --- |
| Глубокий тёмно-синий | `#0D1644` |
| Активный синий | `#234DE7` |
| Aqua | `#5AE3ED` |
| Светлый фон | `#F5F5FC` |
| Белый | `#FFFFFF` |

Разрешён градиент `#0D1644 → #234DE7 → #5AE3ED`. Другие цвета — только нейтральные технические оттенки для глубины и читаемости; случайные яркие акценты не добавлять.

| Режим | Когда выбирать | Образ |
| --- | --- | --- |
| **DARK TECH** | Сильный тезис, проблема СМК, стратегия | Тёмная основа, синий/aqua, digital-глубина и умеренное свечение. |
| **LIGHT TECH** | Образовательный, экспертный, практический материал | Светлый фон, воздух, чистая композиция и фирменные акценты. |
| **SYSTEM / NETWORK** | Процессы, события, аудиты, данные, организационная память | Смысловые узлы, связи, маршруты, последовательности и информационные слои; без образа молекулы. Может сочетаться с тёмной или светлой основой. |
| **PRODUCT / INTERFACE** | Реальная функция или сценарий AUQNI | Только предоставленный реальный интерфейс AUQNI; фиктивные экраны и product screenshots не генерировать. |

## Бренд-ассеты: проверка файлов

Проверены пиксели и alpha-канал PNG из `visual-references/brand`, а не внешний вид миниатюр.

| Файлы | Фактическое состояние | Применение |
| --- | --- | --- |
| `auqni-logo-full-{white,navy,gradient}-transparent.png`, `auqni-mark-q-{white,navy,gradient}-transparent.png` | Шесть RGBA PNG с прозрачным фоном, подготовлены детерминированно из исходных масок AUQNI | Предпочтительные готовые ассеты для наложения поверх карточки; выбирать цвет по контрасту фона, сохранять пропорции. |
| `auqni-logo-positive-navy-on-white.png`, `auqni-logo-positive-gradient-on-white.png` | RGBA, alpha везде 255; белая физическая подложка | Полный AUQNI для белого или почти белого поля без искусственной плашки. Не накладывать на произвольный фон как прозрачный логотип. |
| `auqni-logo-primary-digital.png` | RGBA, alpha везде 255; тёмно-синий/синий/голубой фон встроен в файл | Полный белый AUQNI только там, где сам файл служит согласованной частью фона. Не накладывать прямоугольником на другую композицию. |
| `favicon-site-positive.png`, `favicon-platforma-negative.png`, `favicon-gradient-wave-v8-preview.png` | RGBA, alpha везде 255; знак Q с физической белой, тёмной или градиентной подложкой | Не использовать как прозрачный Q поверх карточки. |
| `auqni-logo-variants-preview.png`, `colors-pattern-v1.png` | Непрозрачные обзорные изображения | Справка, не готовый логотип для вставки. |
| `auqni-gradient-primary-digital.png` | RGBA с переменной alpha; это градиент без логотипа | Палитра/фон, не знак AUQNI. |

В `visual-references/brand` теперь есть прозрачные PNG полного логотипа и знака Q в трёх фирменных цветовых вариантах. Если ни один из них не читается на выбранном фоне без подложки, **пропустить логотип и сообщить об этом**, не генерировать и не вырезать его. Новый цветовой вариант возможен только при отдельной задаче на детерминированное преобразование утверждённого оригинала без изменения геометрии.

Любой используемый оригинальный ассет размещать с сохранением пропорций: `contain`, без растяжения, сжатия, перестановки элементов полного логотипа, изменения знака Q и автоматической прямоугольной плашки. Нейросеть не создаёт логотип, фирменный текст или интерфейс.

## Подготовка карточки

Основной Telegram-формат — **1200 × 1200 (1:1)**. Дополнительный **1080 × 1350 (4:5)** выбирается, если тема выигрывает от вертикальной композиции. Панорамный 2048 × 768 не использовать как стандарт.

AI может создавать смысловой фон, абстрактную digital-графику, сеть, пространство, фактуры и 3D-метафоры. Предпочтительная последовательность: AI-фон → детерминированная компоновка → настоящий короткий текст → оригинальный логотип, если пригодный ассет существует. Текст и логотип не поручать генератору изображения. Людей добавлять только по смысловой необходимости. Не использовать автоматически врача со спины или с планшетом, стетоскоп, коридор больницы, медицинский крест, generic corporate team, робота, электронный мозг или holographic dashboard. Избегать мелкого текста, чрезмерного cyberpunk/neon и декоративности без связи с содержанием.

Перед выдачей проверить: одна главная мысль; режим соответствует теме; нет лишнего текста; цвета в палитре; оригинальный бренд-ассет использован только если он подходит; его пропорции сохранены; нет искусственной плашки; нет выдуманного интерфейса AUQNI; карточка читается на телефоне и выглядит частью AUQNI, а не случайным AI-art. Если подходящего ассета нет, явно зафиксировать отсутствие логотипа в результате.
